# Changelog

## [1.0.0] - Initial stable-release candidate

- Added terminal playback controls.
- Added shuffle, sequential and repeat modes.
- Added playlist selection and filename search.
- Added library refresh.
- Added persistent playback history and history playback.
- Added configuration persistence.
- Added error logging and playback-error handling.
- Added Windows, Linux and macOS installation notes.

This release still requires platform-specific testing before claiming verified compatibility on every listed operating system.
